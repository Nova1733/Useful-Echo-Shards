# Useful Echo Shards
Normally, Echo Shards are almost completely useless, especially for an item obtained from a structure like the Ancient City. This mod attempts to make them useful in a vanilla-like way by allowing them to be used to repair any item in an anvil without increasing its repair cost.

# Details
- Increases the amount of Echo Shards that spawn in Ancient Cities to roughly 1 stack per city.
- Adds 2 new item tags: ```universal_repair_ingredients``` and ```skips_repair_cost_increase```.
  - Items in ```universal_repair_ingredients``` can be used to repair any item in an anvil.
  - Items in ```skips_repair_cost_increase``` do not increase the result item's repair cost when used to repair an item in an anvil.

# Why?
Because I felt like it. Yes, most players would probably just beeline straight for Mending and completely skip over the section of the game where this mod would be useful. This mod is moreso just to give Echo Shards any actual use, while also providing a way to repair items like bows that have no dedicated repair material.
